가정법 과거 (현재 사실 반대) vs 가정법 과거완료 (과거 사실 반대)

📌 학습 전 핵심 개념 가이드

가정법을 배울 때 가장 중요한 포인트는 "말하고자 하는 실제 시점"과 "문법적으로 사용하는 동사의 시제"가 한 단계씩 차이가 난다는 점입니다. 실제 사실과 반대되거나 일어나기 힘든 상상을 할 때 동사의 시제를 과거로 한 칸 되돌려 표현합니다.

현재 사실 반대

1. 가정법 과거 (Hypothetical Present)

"지금 ~라면, …할 텐데" (현재 상황을 아쉬워하며 가상)

If절: If + 주어 + 동사 과거형 (be동사는 were)
주절: 주어 + would/could/might + 동사원형

실제 사실 (평서문): It is hot, so I open the window. (날씨가 덥다.)

가정법 표현: If it were cold, I would close the window.
(만약 날씨가 춥다면, 창문을 닫을 텐데.)

과거 사실 반대

2. 가정법 과거완료 (Hypothetical Past)

"당시에 ~했었더라면, …했었을 텐데" (과거의 일을 후회/가상)

If절: If + 주어 + had + p.p.
주절: 주어 + would/could/might + have + p.p.

실제 사실 (평서문): I didn't study, so I failed the exam. (공부를 안 해서 떨어졌다.)

가정법 표현: If I had studied, I could have passed the exam.
(내가 공부했었더라면, 시험에 합격할 수 있었을 텐데.)
